# Flappy Bird - Python Version

A simple implementation of the classic Flappy Bird game using Python and Pygame.

## Requirements

- Python 3.6+
- Pygame

## Installation

1. Clone this repository:
```
git clone https://github.com/GurpinderSingh96/Flappy_bird.git
```

2. Install the required packages:
```
pip install -r requirements.txt
```

## How to Play

1. Run the game:
```
python flappy_bird.py
```

2. Game Controls:
   - Press SPACE to make the bird jump
   - Press R to restart the game after game over

## Game Features

- Simple physics-based gameplay
- Randomly generated pipes
- Score tracking
- Game over screen with restart option
